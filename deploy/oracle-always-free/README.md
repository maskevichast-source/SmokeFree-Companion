# Переезд SmokeFree Companion на Oracle Cloud Always Free + Neon

Итог: бот и мини-апп крутятся на собственной бесплатной навсегда виртуалке
(Oracle Cloud "Always Free"), а данные хранятся в бесплатном постоянном
Postgres (Neon) — деплои и рестарты сервера больше не стирают базу.

Части ниже нужно сделать один раз, руками, через веб-интерфейсы (это твои
личные аккаунты — сделать это за тебя я не могу). Всё, что можно
автоматизировать, автоматизировано в `setup.sh`.

---

## Шаг 1. База данных — Neon (5–10 минут)

1. Зайди на **https://neon.tech**, зарегистрируйся (можно через GitHub —
   без банковской карты).
2. Create a project → любое имя, регион — ближайший (например Frankfurt/AWS
   eu-central-1, для Астаны это обычно быстрее, чем US).
3. В разделе **Connection Details** переключи вариант подключения на
   **Pooled connection** (это важно — у free-тарифа маленький лимит прямых
   подключений, а через pooler бот не будет в него упираться).
4. Скопируй строку вида:
   ```
   postgresql://neondb_owner:AbCdEf123@ep-cool-thing-12345-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   Она понадобится на шаге 3 как `DATABASE_URL`. Больше в Neon делать
   ничего не нужно — таблицы создаст сам бот при первом запуске.

---

## Шаг 2. Виртуалка — Oracle Cloud Always Free (15–20 минут)

1. Зайди на **https://signup.oraclecloud.com**, зарегистрируй аккаунт.
   Попросят карту — это только для подтверждения личности, Oracle прямо
   гарантирует, что ресурсы в рамках Always Free не тарифицируются.
2. В консоли: **Menu → Compute → Instances → Create instance**.
3. **Image and shape → Edit**:
   - Image: **Canonical Ubuntu 24.04** (Minimal, если будет выбор).
   - Shape: **VM.Standard.A1.Flex** (Ampere, ARM) — поставь 1 OCPU / 6 GB
     RAM, это часть Always Free. Если увидишь ошибку **"Out of host
     capacity"** — это известная особенность именно бесплатных ARM-инстансов
     Oracle в загруженных регионах: попробуй ещё раз через несколько минут,
     или смени **Availability Domain** в том же регионе. Если совсем не
     получается — возьми шейп **VM.Standard.E2.1.Micro** (AMD, x86,
     1 vCPU / 1 GB RAM), он тоже бесплатен навсегда и без такой проблемы;
     этому боту хватит и его.
4. **Add SSH keys**: выбери "Generate a key pair for me" и сразу скачай
   приватный ключ (`.key`/`.pem`) — он даст доступ к серверу. Храни его как
   пароль, второй раз скачать нельзя.
5. Остальное — по умолчанию. **Create**. Через 1–2 минуты статус станет
   **Running** — на странице инстанса будет виден **Public IP Address**,
   он понадобится дальше.
6. **Открыть порты 80/443** (для HTTPS мини-аппа): на странице инстанса →
   **Subnet** → **Default Security List** → **Add Ingress Rules** — добавь
   два правила: `0.0.0.0/0`, TCP, порт **80**, и то же для порта **443**.
   Без этого шага сайт снаружи не откроется, даже если сервер работает.

## Шаг 3. Подключение и запуск (5 минут)

Со своего компьютера (Windows — через PowerShell, PuTTY или WSL):

```bash
chmod 600 путь/к/скачанному-ключу.key
ssh -i путь/к/скачанному-ключу.key ubuntu@PUBLIC_IP
```

На сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/maskevichast-source/SmokeFree-Companion/main/deploy/oracle-always-free/setup.sh -o setup.sh
sudo bash setup.sh
```

Скрипт спросит:
- **BOT_TOKEN** — токен от @BotFather (тот, что уже используется).
- **GEMINI_API_KEY** — тот же, что был на Railway.
- **DATABASE_URL** — строка из Шага 1 (Neon).

Дальше всё сам: поставит Python, Caddy, откроет файрвол (включая
специфичную для Oracle засаду с iptables), склонирует репозиторий, поднимет
бота как systemd-службу с автозапуском и автоперезапуском при падении, и
выпустит настоящий HTTPS-сертификат на адрес вида
`https://ВАШ-IP-ЧЕРЕЗ-ДЕФИСЫ.sslip.io` — домен покупать не нужно.

В конце скрипт напечатает этот адрес.

## Шаг 4. Погасить старый Railway-деплой

**Важно сделать именно сейчас**, пока новый бот уже поднялся, а старый ещё
не остановлен — два одновременных поллинга с одним и тем же BOT_TOKEN
конфликтуют, Telegram начнёт присылать `409 Conflict`, и бот будет мигать.

В Railway: открой сервис → **Settings** → либо **Remove Service**, либо
просто останови деплой (down/pause), если хочешь оставить проект как архив.

---

## Шаг 5. Мини-апп в Telegram

Если в @BotFather настроена постоянная кнопка меню (`/setmenubutton`) —
обнови её URL на тот, что напечатал `setup.sh`. Если мини-апп открывается
только через инлайн-кнопку внутри бота (`🚀 Открыть трекер`) — ничего
менять не нужно, она уже возьмёт новый адрес из `WEBAPP_URL`, который
скрипт прописал сам.

---

## Дальнейшие обновления

Когда я (или ты) push-ите изменения в `main` на GitHub, на сервере нужно
подтянуть их одной командой:

```bash
ssh -i путь/к/ключу.key ubuntu@PUBLIC_IP
sudo bash /opt/smokefree/app/deploy/oracle-always-free/update.sh
```

Она сама сделает `git pull`, обновит зависимости и перезапустит службу без
простоя дольше пары секунд.

## Диагностика

```bash
systemctl status smokefree-bot     # запущен ли бот
journalctl -u smokefree-bot -f     # логи бота в реальном времени
journalctl -u caddy -f             # логи HTTPS-прокси
```
